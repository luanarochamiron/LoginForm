# Login Form

Um formulário de login moderno, limpo e responsivo desenvolvido com HTML5 e CSS3. O projeto apresenta uma interface de autenticação intuitiva com campos estruturados, blocos de ícones integrados e uma paleta de cores harmoniosa focada em tons de verde e branco.

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do formulário de autenticação (`<form>`, `<input>`).
* **CSS3:** Estilização, gerenciamento de cores, bordas arredondadas e efeitos de sombra.
* **Flexbox / CSS Grid:** Alinhamento centralizado do card na tela e organização interna dos campos.
* **Fontes e Ícones:** Integração de ícones vetoriais para os campos de usuário e senha.

## Funcionalidades e Técnicas Aplicadas

* **Campos de Input Customizados:** Caixa de texto dividida com ícones identificadores (E-mail/Telefone e Senha) integrados à esquerda.
* **Estilização de Estados (Hover & Focus):** Mudanças visuais sutis e interativas nos botões e links ao passar o mouse ou focar nos campos.
* **Links de Navegação:** Inclusão de links de suporte funcionais como "Forgot password?" (Esqueci a senha) e "Signup now" (Cadastre-se agora).
* **Interface Centralizada:** Uso de técnicas de posicionamento CSS para manter o formulário perfeitamente alinhado no centro da página de fundo esmeralda.
